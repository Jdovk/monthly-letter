# Background music

Put your chosen audio file in this folder and name it exactly:

`background.mp3`

The website loads it from `assets/music/background.mp3`, so the music is part of the website and visitors do not need to upload anything.

- Use an MP3 file for the simplest compatibility.
- Only upload music you created or have permission to distribute.
- The player starts at 20% volume.
- Moving the slider to 0% pauses playback. Raising it again resumes if it was playing before being muted.
